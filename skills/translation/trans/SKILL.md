# Trans：英文 md 文档翻译

## 适用场景

- 翻译英文 Markdown 文档（README、教程、笔记、博客）为中文

## 步骤

1. **通读全文，建立术语表**：提取专有名词、技术词、项目名，逐个决定译法（保留英文 / 常用中文译名）。完成标准：术语表覆盖文中全部专有名词，每个词有且仅有一种译法。
2. **逐节翻译**：以「信达雅」为标准——先忠实原意，再通顺成文。标题、列表、表格、链接、粗斜体等 Markdown 结构原样保留；frontmatter 的键名与代码块整体原样保留，frontmatter 的描述类值一并翻译。完成标准：全文每一段都有对应译文，结构与原文一一对应。
3. **校对**：对照原文逐节检查——代码块、命令、路径、链接、图片引用未被改动；术语表中的词全文译法一致；译文单独成篇可读。完成标准：对译文跑 `grep` 抽查代码块与链接均与原文一致。

## 注意事项

- 译文写到原文旁的 `<原文件名>.zh-CN.md`，原文件保持不动，一律不修改原文。
- 术语首次出现时括注英文原词，如「深度模块（deep module）」，之后只用中文。
- 原文里的幽默、比喻优先找中文等价表达，找不到再直译加括注。
