# No-Code

## 适用场景

- 用户想查看命令输出、验证环境、确认信息，但明确不希望改动任何代码或文件
- 命令可能产生副作用（编译、测试、格式化、安装、迁移）时，需要"只观察、不落盘"

## 步骤

1. 判断命令是否会改动代码或文件（写入、删除、覆盖、生成产物）。
2. 若会改动，优先使用只读/试运行方式（如 `--dry-run`、`--check`、`--help`）。
3. 执行命令，只把文本结果返回给用户。
4. 若无法避免副作用，先说明会改动什么，等用户确认后再执行。

## 注意事项

- 不要顺带做 git commit、改动代码、新建文件等任何额外操作。
- 命令若会修改文件，先说明再执行，绝不静默改动。
